# Spark-X2.6-4B deployment hub: sources and coverage

Research date: 2026-11-13 (UTC). Page: `/demo#spark-x26-deploy`.

This update adds 19 route cards. Each card provides the original installation or integration entry, steps, version/hardware conditions and public examples where available. Officially documented paths and community implementations are labeled separately. Website build/browser checks do **not** mean that the model was installed or benchmarked on all listed devices.

## Coverage and unresolved verification

- Completed: all 19 route cards researched and linked; 45 distinct external card links passed an HTTP GET connectivity check. A successful HTTP response is not a successful installation or model inference.
- Runtime testing outstanding: no model inference was executed for these 19 route cards during this website update. Official and author-reported results retain their original scope.
- Four specific evidence limits: independent Spark-specific LM Studio walkthrough; independent Spark-specific Unsloth Studio walkthrough; current iOS in-app 4B catalog; independent phone/device installation and performance testing. Relevant cards retain these limits. The first two still have official Spark setup/support instructions.
- No X2.6-specific RK3588/Hygon/Houmo recipe is claimed. Generic runtime backend support and older X2.5 examples do not prove a working X2.6 4B deployment on those devices.
- FlashHub frontend is a JavaScript app. Its HTML initially exposed no README; the published frontend asset identified its public repository API, whose repository-37 response was then read in full. This resolved the initial extraction gap without inventing commands from search snippets.
- Pi original-page direct fetch initially returned 403. Original publisher content was available in web search and later connectivity checks passed; no claim of rerunning its benchmark.
